# 10_data_mgmt

This folder contains the Data Management Plan documentation for the doctoral research project.

## Observation 2 — Construct Measurement and Pipeline Alignment
The data-management documentation explicitly links the study's three central constructs — Digital Transformation Maturity, Educational Quality, and Institutional Efficiency — to dimensions, indicators, planned measures, data sources, and analytical variables. See `CONSTRUCT_OPERATIONALIZATION.md` and `DATA_DICTIONARY.md`.

The current pipeline uses synthetic microdata only as a reproducibility proof-of-concept. Synthetic features and demonstration metrics are not empirical findings. Exact validated instruments, scoring rules, and empirical variable mappings will be finalized after instrument selection, expert validation, and pilot testing.
