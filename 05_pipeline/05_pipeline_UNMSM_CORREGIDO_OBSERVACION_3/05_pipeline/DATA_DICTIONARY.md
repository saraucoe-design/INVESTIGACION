# Data dictionary

## Demonstration dataset

| Variable | Type | Meaning |
|---|---|---|
| record_id | string | Synthetic record identifier |
| year | integer | Observation year (synthetic) |
| faculty | categorical | Synthetic faculty code |
| role | categorical | Student, faculty, administrative or manager |
| digital_infrastructure_score | numeric 0–100 | Perceived infrastructure availability |
| digital_competence_score | numeric 0–100 | Digital capability |
| platform_reliability_score | numeric 0–100 | Reliability of platforms |
| digital_governance_score | numeric 0–100 | Governance and strategic alignment |
| process_automation_score | numeric 0–100 | Degree of process automation |
| change_readiness_score | numeric 0–100 | Readiness for organizational change |
| student_service_access_score | numeric 0–100 | Accessibility of student services |
| teaching_support_quality_score | numeric 0–100 | Quality of digitally enabled teaching support |
| user_satisfaction_score | numeric 0–100 | Overall satisfaction |
| processing_time_hours | numeric | Administrative processing time |
| error_rate_pct | numeric | Process error rate |
| high_quality_efficiency | binary | Demonstration target: 1 = high combined outcome |

**The demonstration records are synthetic and are not official UNMSM observations.**


## Interpretation status

All variables in the demonstration microdata are provisional pipeline features. Their current values and model-derived metrics are for reproducibility testing only. Authorized empirical data and validated construct-to-variable mappings must replace them before substantive analysis.
