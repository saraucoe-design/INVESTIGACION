# Data Lifecycle

Instrument/model selection -> Expert validation -> Pilot testing -> Collection -> Validation -> Anonymization -> Construct/indicator coding -> Dataset feature mapping -> Preprocessing -> Analysis/model training -> Evaluation -> Archival -> Secure disposal.

At the construct/indicator coding stage, every empirical variable must be traceable through:

**Construct -> Dimension -> Indicator -> Survey/Institutional Measure -> Dataset Feature -> Analysis**

Synthetic proof-of-concept variables remain clearly separated from future authorized empirical data throughout the lifecycle.
